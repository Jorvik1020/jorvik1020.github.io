Privacy policy

Applies to the "rclone" Google OAuth client owned by the GitHub user Jorvik1020. Last updated 24 November 2026.

Who uses it

Only the owner. The app is a personal tool and is not offered to anyone else.

What data it accesses

With the owner's consent, rclone reads and writes files in the owner's own Google Drive, on the owner's own computer.

What happens to the data

  • Files are copied only between the owner's Google Drive and the owner's own computer.
  • No data is sent to the app's developer or to any third party, and nothing is sold or used for advertising.
  • The access token is stored only in the rclone configuration on the owner's computer.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
